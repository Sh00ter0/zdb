# Security Policy

## Supported Versions

Currently, the project is in the active development phase and has not yet reached its first official, stable release. Because the software is still under construction, there are no specific versions officially supported with dedicated security patches at this time. 

| Version | Supported          |
| ------- | ------------------ |
| Pre-1.0 | Work in Progress   |

## Reporting a Vulnerability

Since the software is currently in the build phase, we are handling all feedback, bugs, and security concerns openly.

If you discover a security vulnerability, misconfiguration, or have any security-related suggestions, please report them by opening a new **Issue** directly in this repository. 

When submitting an issue, please include as much context as possible:
* A clear description of the vulnerability or concern.
* Steps to reproduce the problem (if applicable).
* Any potential impact you foresee.

We review new issues regularly. You can expect an initial response or status update directly within the issue thread as we evaluate and address the concern as part of our ongoing development cycle.
