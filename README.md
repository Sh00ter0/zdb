<h2 align="center">Zabbix Discord-Bridge</h2>

<br>

Alternative solution designed to offer more than standard webhook delivery from Zabbix. It is a centralized application that enables receiving and managing alerts from multiple Zabbix servers simultaneously.

# `>_` Key features
- Integration with a dedicated `Media Type` for Zabbix
- Receiving and delivering notifications to recipients using `Discord IDs`
- Support for the following channel types: `Direct Message`, `Text Channel`, `Voice/Stage Text Channel`, `Public/Private/Forum Threads`, and `Announcement Channels` with optional `automatic` publishing
- Ability to `manage` alarms `directly` from received `private messages` through a bidirectional `API integration` with Zabbix
- Ability to configure `multiple servers` simultaneously with isolated API key policies
- And much more, development of the application has only just begun...
---

# `>_` Future plans
- Deployment of an internal agent enabling stability and performance monitoring of the ZDB application along with a dedicated template for Zabbix
- Deployment of a Discord server agent enabling the collection of diagnostic, informational, and statistical data from monitored servers
---

# `>_` Supported Zabbix Server versions
- Not yet determined, development is currently being conducted on version `7.x.x`.
